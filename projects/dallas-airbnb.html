Dallas Airbnb Dashboard

Tableau

An interactive Tableau dashboard analyzing Dallas Airbnb listings, nightly prices, neighborhood distribution, and calendar availability using a 2026 data snapshot.

Project Overview

This project explores the Dallas short-term rental market by examining where Airbnb listings are located, how nightly prices vary across neighborhoods and property characteristics, and how listing availability differs throughout the market.

Data Source

The analysis uses 2026 listings and calendar data from Inside Airbnb. Because the available files did not contain ZIP codes, Dallas neighborhood district boundaries were incorporated through a geographic data file to support a district-level spatial analysis.

Data Preparation

Listing information was combined with calendar availability data and geographic district boundaries. Calculated fields were created to measure the percentage of days available and to support comparisons of listing prices, bedrooms, neighborhoods, and other property characteristics.

Tableau Dashboard

View Interactive Dashboard

The dashboard includes a district-level map showing the geographic distribution of listings, comparisons of nightly prices across property characteristics, and visualizations of calendar availability.

Interactive filters allow users to examine particular neighborhoods and listing characteristics. Both total and median price measures were considered to distinguish overall market activity from the typical price of an individual listing.

Skills Demonstrated

  • Tableau dashboard development
  • Data cleaning and preparation
  • Calculated fields and data aggregation
  • Geospatial mapping with GeoJSON data
  • Interactive filters and dashboard navigation
